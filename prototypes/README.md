# النموذجان الأوليان (Prototypes)

| الملف | ما هو |
|---|---|
| `M_Group_App.html` | تطبيق الجوال للفريق والعملاء: بوابات الشركاء والفريق والعملاء |
| `M_Group_Website_Console.html` | واجهة الشركاء والإدارة على سطح المكتب |

الملفان نسختان مصحّحتان وفق `docs/PROJECT_POLICY.md`. تفاصيل ما صُحّح، وما ينتظر قراراً، وخطة التوحيد
مع النظام المبني في [`docs/PROTOTYPES_REVIEW.md`](../docs/PROTOTYPES_REVIEW.md).

**تنبيه:** النموذجان للعرض والتصميم فقط، وكل بياناتهما تجريبية. لا تُدخل فيهما بيانات عميل حقيقية، فهما
يحفظان في متصفح المستخدم. النظام الفعلي للعمل هو `backend/` و`frontend/`.

## الفتح

افتح أي ملف مباشرة في المتصفح، فلا يحتاج خادماً ولا اتصالاً بالإنترنت. كلمة مرور الحسابات التجريبية
`Mg@2026`، ورمز التحقق يظهر على الشاشة في النسخة التجريبية.

## البنية

كل ملف "حزمة" واحدة تحمل داخلها الكود والبيانات والخطوط مضغوطة. للقراءة والمراجعة نُسخت المصادر
المصحّحة إلى `src/`:

| المسار | المحتوى |
|---|---|
| `src/app/template.html` | واجهة التطبيق ومنطقه |
| `src/app/mg-data.js` | بيانات التطبيق: النصوص، والكتالوج، والمكتبة، والبيانات التجريبية. تشترك فيه الحزمتان |
| `src/console/template.html` | واجهة الإدارة ومنطقها |
| `src/console/mg-console.js` | بيانات الإدارة التجريبية: الشركة، والفريق، والعملاء، والملفات، والتكاملات |

## التعديل

```bash
cd prototypes/tools
node unbundle.cjs ../M_Group_App.html app            # يفك الحزمة إلى app/template.html وapp/assets/*
# … عدّل app/template.html أو ملفات app/assets …
node rebundle.cjs ../M_Group_App.html app ../M_Group_App.html
```

- **الكتالوج:** مصدره الوحيد `website/src/data/catalog.ts`. عند تعديله يُعاد توليد `axes.json` بالأمر
  `node --experimental-strip-types export-cat.mjs`، بعد نسخ الملف إلى `cat.mts`. ثم يُستبدل سطر `D.axes`
  في بيانات الحزمتين.
- **سجل التصحيح:** `fixbundles.py` هو سكربت التصحيح الذي طُبّق على الملفين الأصليين، ويبقى سجلاً لما
  تغيّر. `fixlog.txt` ناتجه.
- **قبل أي نشر:** ابحث في المصادر عن الكلمات الممنوعة وفق سياسة المشروع: "توثيق" بمعنى الخدمة، و"فروع"
  و"مقرات"، و"الرئيس التنفيذي" و"المؤسس"، و"LAW FIRM"، وخدمات عسكرية أو فضاء أو عملات مشفرة، وأي
  استدعاء لخدمة خارجية. ثم افتح الملف وتأكد أن وحدة التحكم في المتصفح بلا أخطاء.
