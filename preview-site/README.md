# نسخة معاينة مؤقتة للموقع العام

نسخة مبنية من `website/` لعرض الموقع مؤقتاً على الجوال قبل نشره على خادم داخل المملكة (www.mgrp.sa):

- الروابط فيها نسبية حتى تعمل من أي مسار.
- في كل صفحة شريط "نسخة معاينة".
- نموذج الطلب معطّل.
- مُعلَّمة بـ noindex فلا تفهرسها محركات البحث.

لا تُعدَّل هنا. مصدر المحتوى `website/`. وتُحذف هذه المجلد عند النشر الرسمي.
