# الموقع التعريفي العام — مجموعة إم القانونية

موقع ثابت ثنائي اللغة (عربي افتراضي، وإنجليزي) مبني بـ [Astro](https://astro.build) بالتوليد الثابت:
كل صفحة HTML جاهزة ومفهرسة، بلا إطار عمل في المتصفح، وبلا أي مورد من طرف خارجي.

## الأوامر

```bash
npm ci
npm run dev        # http://localhost:4321/ar/
npm run build      # فحص الأنواع (astro check) ثم البناء إلى dist/
npm run preview
node scripts/generate-assets.mjs   # إعادة توليد الأيقونات وصورة المشاركة عند تغيير الشعار
```

## أين يُعدَّل المحتوى

| المحتوى | الملف |
|---|---|
| الخدمات والمحاور (المصدر الوحيد، ويقرؤه خادم الاستقبال أيضاً) | `src/data/catalog.ts` |
| بيانات الشركة: السجل، الترخيص، الرقم الضريبي، العنوان، الشركاء، التغطية، الحسابات | `src/data/company.ts` |
| نصوص الواجهة بالعربية والإنجليزية | `src/i18n.ts` |
| سياسة الخصوصية وشروط الاستخدام | `src/content/legal/*.md` (وتاريخ الإصدار في `company.ts` وصفحة الشروط) |
| المقالات والمستجدات النظامية | `src/content/articles/*.md` |

## سياسة المحتوى (إلزامية)

1. **لا خدمة بلا إطار نظامي نافذ يحكمها**، ولا خدمة تمس الأمن الوطني، ولا خدمة تتطلب ترخيصاً لا تحمله
   الشركة إلا بصيغة التعاقد مع جهة مرخّصة (`delivery: 'licensed-partner'`). الحقل `basis` في كل خدمة يسجل
   الإطار النظامي للمراجعة الداخلية.
2. **خدمتا الشراكة الاستراتيجية** (النقل والطاقة): `delivery: 'strategic-partnership'` — يظهر تلقائياً النص
   النظامي المعتمد في صفحة الخدمة، ولا يُذكر اسم أي جهة خارجية.
3. **المصطلح النظامي:** "نظام" لا "قانون" عند الإشارة إلى تشريع سعودي، ولا إشارة إلى تشريع غير موجود.
4. **لا صيغة وعد:** لا "حكم لصالحك"، ولا "نضمن"، ولا وصف تفاضلي غير قابل للتحقق.
5. **لا أسماء عملاء أو جهات** في أي نص ما لم يوجد إذن مكتوب.
6. **أرقام الخبرة** تُعرض دائماً مع التوضيح بأنها حصيلة الأعمال السابقة للشركاء.
7. **المقالات:** لا تُنشر إلا بحالة `reviewed` واسم المحامي المراجِع ومصدر رسمي واحد على الأقل
   (يفرضه مخطط `src/content.config.ts` عند البناء). المسودات لا تُبنى.
8. أي تعديل في الخدمات أو السياسات يراجعه محامٍ مرخّص قبل النشر.

## الهوية

الألوان والخط من الهوية الرسمية فقط (`src/styles/global.css`): كحلي `#0F2A46`، كحلي عميق `#0A1B2E`، ذهبي
`#A9812F`، كريمي `#FDFBF6`، ونص `#1A1A1A`؛ وخط **Noto Naskh Arabic** مستضاف ذاتياً لكل النصوص، بلا خط مائل.
الشعار `src/assets/logo-mark.svg` مستخرج متجهياً من ملف الشعار الرسمي، ويُعرض على لوح كريمي بإطار ذهبي
وبارتفاع لا يقل عن 4.25rem لتبقى كلمة GROUP مقروءة.

## ما يلزم من الشركة

- **صورة الواجهة:** الصورة الحالية لكافد بعرض 1080 بكسل (من الملف الأصلي). يُنصح بتوفير صورة أصلية بعرض
  2560 بكسل أو أكثر، واستبدال `src/assets/kafd-night.jpg`، وإضافة 1920 و2560 إلى `widths` في
  `src/pages/[lang]/index.astro`.
- مراجعة الاسم الإنجليزي للمحامية المرخّصة في `company.ts`، والاسم التجاري الإنجليزي كما في السجل.

## الفحوص التي اجتازها البناء الحالي

- Lighthouse (محاكاة جوال): الأداء 97–99، الوصول 100، أفضل الممارسات 100، محركات البحث 100.
- axe-core (WCAG 2.2 AA): صفر مخالفات على 13 صفحة تمثيلية.
- يعمل تحت سياسة CSP صارمة (`script-src 'self'`، بلا سكربتات أو أنماط مضمّنة).
- النموذج يعمل بـ JavaScript وبدونه.
